# 공모전 요강 요약

현대자동차그룹 차량용 앱 개발 공모전 (Code your App into Pleos App Market). 2026-11-03에 공식 사이트에서 확인한 내용입니다.

- 공식 사이트: https://appdevchallenge.auto-hmg.io/

## 개요

- **주제:** 차량 데이터와 기능, 이동 상황을 활용해 운전자와 탑승자에게 새로운 경험을 주는 앱
- **참가 대상:** 대학(원)생, 일반인, 스타트업 (개인 또는 최대 5인 팀)
- **시상 부문:** 대학생 / 일반(스타트업 포함)

## 일정

| 단계 | 날짜 |
| --- | --- |
| 접수 | 2026-10-21 ~ 11-15 |
| 온라인 설명회 | 2026-10-28 (다시보기 제공) |

| 최종 선정 발표 | 2026-12-18 |
| 전시·시상식 | 2027-02 |

## 제출물

| 항목 | 필수 여부 | 내용 |
| --- | --- | --- |
| 접수양식(기획서, DOCX) | 필수 | 개인정보 동의서 포함, 팀원 전원 서명 |
| 시연 영상 | 선택 (가산점) | 목업·프로토타입·화면 녹화 인정 |
| GitHub 저장소 | 선택 (가산점) | 소스 코드 + APK (`apk/팀명_앱이름_release.apk`), README 포함 |
| 숏폼 링크 | 선택 (가산점 없음) | 별도 숏폼 챌린지 시상 |

- **제출 방법:** appdevchallenge@hyundai-partners.com 으로 이메일
- **제목 형식:** `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명`, 팀원 전원 참조(CC)
- **수정 제출:** 마감 전 같은 주소로 `[수정제출]` 제목을 붙여 다시 보내며, 마지막 제출본이 최종본
- **접수양식 5번:** Pleos Connect 구현 방식, 주요 개발 범위, SDK/API 사용 계획을 구체적으로 작성
- **비공개 저장소:** 심사용 GitHub 계정을 Collaborator로 초대
- **2차 PT 대상 팀:** PT 전까지 실제로 동작하는 앱을 완성해야 함

- 최종 10팀은 현장 시연용 APK를 제출하고 2027년 2월 행사에서 직접 전시·시연합니다.

## 개발 환경

- Android API 28 이상, Gradle 8.0 이상, Java 또는 Kotlin
- 사용 가능한 SDK: Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation
- Pleos Connect 전용 에뮬레이터(AVD)로 개발·검증

## 숏폼 챌린지 (선택)

- 30초~1분 세로 영상을 Instagram 릴스 또는 YouTube Shorts에 게시
- 필수 해시태그 #HMG차량용앱개발공모전 포함, 해시태그는 총 2~3개
