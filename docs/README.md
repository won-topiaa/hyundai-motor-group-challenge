# 현대자동차그룹 차량용 앱 개발 공모전 — Calm Ride

전기차 동승자의 멀미를 소리로 줄이는 Pleos Connect 차량용 앱 기획 자료입니다. (정리일: 2026-11-04)

- **핵심 아이디어:** 출발 전 1분 100Hz 사운드 + 주행 중 경로 예고음 + 운전자별 맞춤(규칙 기반)
- **참가 부문:** 대학생 부문
- **기획서 온라인 문서 (편집·댓글 가능):** https://claude.ai/artifact/YLvmF4gPcCz8MJh336gXBn
