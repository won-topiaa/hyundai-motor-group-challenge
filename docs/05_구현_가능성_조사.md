# Calm Ride 구현 가능성 조사

Pleos Connect 공식 문서 34개 페이지와 AOSP 소스를 확인했습니다. (조사일: 2026-11-03)

**결론:** 핵심 기능은 대부분 만들 수 있고, 에뮬레이터에서 시연도 됩니다. 다만 세 가지는 계획을 바꿔야 합니다.

- **LLM SDK:** 제공이 종료됐습니다 (에뮬레이터 v2.1.0, 2026-10-19).
- **차속:** Vehicle SDK가 아니라 AAOS 표준 API(`PERF_VEHICLE_SPEED`)로 읽어야 합니다.
- **회생제동 단계:** 읽을 수는 있지만 앱이 직접 바꿀 수는 없습니다.

## 1. 기능별 구현 가능 여부

| 기능 | 쓰는 API | 권한 | 에뮬레이터 시연 | 판정 |
| --- | --- | --- | --- | --- |
| 100Hz 1분 사운드 | Android `AudioTrack` + 오디오 포커스 요청 | 없음 | 가능 | 가능 |
| 정차 판단 | AAOS `GEAR_SELECTION` + `PERF_VEHICLE_SPEED` | `CAR_POWERTRAIN`(normal), `CAR_SPEED`(dangerous, 실행 중 동의) | 기어는 Virtual Console로 가능, 속도는 확인 필요 | 가능 |
| 제동 시작 예고 | Vehicle `registerBrakePedalStatus` | `pleos.car.permission.CAR_DRIVE` | 가능 (Brake Pedal 0~100%) | 가능 |
| 차선 변경 예고 | Vehicle `registerTurnSignalState` | `pleos.car.permission.CAR_LIGHTS` | 가능 (Turn Signal) | 가능 |
| 회전 중 감지·습관 학습 | Vehicle `registerSteeringWheelAngle` | Vehicle SDK 권한 | 가능 (−540~540°) | 가능 |
| 환기 (외기 유입·풍량) | Vehicle `setHvacRecirculation`, `setHvacFanSpeed` | `pleos.car.permission.CONTROL_CAR_CLIMATE` | 가능 (Air Recirculation, Fan Speed) | 가능 |
| 음성 명령·안내 | SpeechToText / TextToSpeech SDK | 각 SDK 권한·앱 등록 | 가능 (에뮬레이터 마이크 설정 필요) | 가능 |
| 회전 예고 | NaviHelper `getTBTInfo()` / `onTBTInfo` → `TBTInfo.distance`, `type` | NaviHelper 권한 | 확인 필요 | 조건부 |
| 방지턱·내리막 예고 | NaviHelper `onCautionPointInfo` → `CautionPoint.remainDistance`, `type` | NaviHelper 권한 | 확인 필요 | 조건부 |
| 회생제동 상태·단계 읽기 | AAOS `EV_REGENERATIVE_BRAKING_STATE`, `EV_BRAKE_REGENERATION_LEVEL` | `CAR_ENERGY`(dangerous), `CAR_POWERTRAIN`(normal) | Virtual Console에 항목 없음 | 조건부 |
| 운전자 구분 (시트 위치) | Vehicle `getCurrentSeatForeAftPosition`, `getCurrentSeatHeightPosition` | `pleos.car.permission.CAR_SEATS` | Virtual Console에 시트 위치 항목 없음 | 조건부 |
| 좌우 스피커 방향 예고음 | `AudioTrack` 스테레오 출력 | 없음 | 에뮬레이터는 PC 스피커로 확인 가능 | 실차 확인 필요 |
| 회생제동 단계 자동 변경 | AAOS `EV_BRAKE_REGENERATION_LEVEL` 쓰기 | `CONTROL_CAR_POWERTRAIN`(signature) | — | **불가** (추천만 가능) |
| LLM 코칭 문장 | LLM SDK | — | — | **불가** (제공 종료) |
| 가속도 센서 | — | — | — | **불가** (차속 변화로 계산) |

## 2. 새로 찾은 활용 포인트

- **뒷좌석 탑승 감지:** `getCurrentSeatOccupancy`로 뒷좌석에 사람이 타면 멀미 모드를 먼저 제안할 수 있습니다. Virtual Console의 Seat Occupancy로 시연도 됩니다.
- **앰비언트 라이트:** `setAmbientLightBrightnessColor`로 예고를 빛으로도 줄 수 있습니다. 다만 운전자 시선 분산 심사에 걸릴 수 있어 선택 기능으로 둡니다.
- **카메라 알림:** `onCameraAlert`에도 남은 거리(`remainDistance`)가 있어, 단속 카메라 앞 급감속도 예고할 수 있습니다.

## 3. 지켜야 할 플랫폼 규칙

- **주행 중 화면:** 주행 최적화(Distraction Optimization, DO)를 선언하지 않은 앱은 주행 중 화면을 쓸 수 없습니다. 그래서 주행 중에는 음성과 소리만 쓰고, 화면은 '멀미 모드 끄기' 정도로 최소화해야 합니다.
- **주행 중 제한 확인:** `CarUxRestrictionsManager`로 제한 상태를 받아 기능을 줄여야 합니다. 테스트는 `adb shell cmd hmg_car_service --service drivingstate driving_regulation on`으로 합니다.
- **오디오 포커스:** 소리마다 `AudioFocusRequest`를 요청하고 포커스 변경을 처리해야 합니다.
  - 예고음은 음악과 함께 들리도록 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`으로 요청합니다.
  - 음성 비서(Gleo)가 호출되면 즉시 소리를 멈춰야 합니다.
- **리소스:** 내비게이션이 아닌 앱은 주행 중 CPU 5% 미만, RAM 400MB 이하를 지켜야 합니다.
- **백그라운드:** 앱은 화면에서 사라져도 백그라운드에 남을 수 있습니다. 예고음 엔진은 포그라운드 서비스로 돌리는 구조가 맞습니다.
- **개인정보:** 운전 중 행동 데이터를 마케팅에 쓰면 안 됩니다. 프로필은 차량 안에만 저장하는 현재 설계가 맞습니다.
- **앱 카테고리:** 주행 중 일부 기능이 허용되는 카테고리는 Music/Audio, Maps/Navigation, Mobility Services입니다. Calm Ride는 Mobility Services(주행과 밀접한 차량 관리 서비스)로 신청하는 것을 검토합니다.

## 4. 개발 환경

- **맥 지원:** 맥용(arm64) 에뮬레이터 이미지가 따로 있습니다.
  - 맥용 URL: `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-arm64-sys-img.xml`
- **설치 순서:** Android Studio의 SDK Manager에서 위 URL을 추가합니다. 그다음 API 34의 Pleos Connect system image를 설치하고 Automotive AVD를 만듭니다.
- **필수 설정:** 부팅은 반드시 **Cold boot**로 해야 합니다(Quick boot면 차량 데이터를 쓸 수 없음). RAM은 4GB로 설정합니다.
- **Virtual Console:**
  - `adb forward tcp:8088 tcp:8088` 실행 후 브라우저에서 `http://127.0.0.1:8088/`을 엽니다.
  - 기어, 브레이크, 조향, 방향지시등, 공조, 좌석 탑승을 조작할 수 있습니다.
- **시연 영상 녹화:** `adb exec-out screenrecord --output-format=h264 - > ~/Desktop/screen.h264` 후 ffmpeg로 mp4로 바꿉니다.
- **SDK 버전 (2026-10-19 기준):** Vehicle v2.3.2, NaviHelper v3.0.5, TTS·STT v3.3.1, FusedLocation v1.1.3

## 5. 단계별 구현 범위 제안

**11/15 접수용 (가산점 영상)**
1. 정차 중 100Hz 1분 재생
2. 브레이크·방향지시등·조향 이벤트로 예고음 재생
3. 멀미 모드에서 외기 유입·풍량 조절
4. 음성으로 멀미 모드 켜기
5. Virtual Console로 조작하는 화면을 녹화

**12/3 PT용 (실제 동작 앱)**
1. NaviHelper 경로 안내와 연동한 회전·방지턱 예고음
2. 차속 기반 정차 판단과 예고 시점 계산
3. 뒷좌석 탑승 감지로 멀미 모드 제안
4. 운전자 프로필과 규칙 기반 맞춤 코칭 (LLM 대신 문장 템플릿)
5. 주행 중 제한·오디오 포커스 정책 대응

## 6. 에뮬레이터에서 직접 확인할 것

- [ ] Virtual Console 또는 Android Emulator의 Car data에서 **차속을 바꿀 수 있는지**
- [ ] NaviHelper `requestRoute()` 후 **모의주행이 되는지**와, `onTBTInfo`가 자동으로 오는지(안 오면 `getTBTInfo()`를 1초마다 조회)
- [ ] 에뮬레이터에서 `EV_REGENERATIVE_BRAKING_STATE`, `EV_BRAKE_REGENERATION_LEVEL` 값이 나오는지
- [ ] `pleos.car.permission.CONTROL_CAR_CLIMATE`가 일반 앱에 허용되는지
- [ ] 앱이 백그라운드일 때 예고음이 정상 재생되는지
- [ ] AAOS 표준 API(CarPropertyManager)를 쓰는 것이 공모전 '기술 활용성' 평가에서 문제없는지 (주최 측 문의 권장)
